Put your own font files here (e.g. .woff2, .ttf) when you have one to add.

Then in style.css, uncomment and fill in the @font-face block near the top
(search for "Custom font example"), and add a matching entry to the FONTS
array in product-custom-text.html so it shows up as a choice in the Font
picker. Google Fonts don't need this folder — see README.md for that path.
